¿Cuándo usar Ajustes, Mermas o Compras?

{# AJUSTE POSITIVO #}
+ Ajuste positivo Sobrante físico

Utilízalo para corregir existencias cuando hay más unidades físicas en almacén que las registradas en el sistema. Por ejemplo, después de corregir un error de conteo.

{# AJUSTE NEGATIVO #}
- Ajuste negativo Faltante físico

Utilízalo para corregir existencias cuando hay menos unidades físicas que las registradas por un descuadre de inventario.

{# MERMA #}
Merma Baja de mercadería

Utilízalo exclusivamente para retirar productos dañados, deteriorados, vencidos, perdidos o no aptos para la venta. La cantidad siempre debe ser negativa.

{# NUEVA COMPRA #}
Nueva compra Ingreso de mercadería

Nunca uses ajustes para registrar mercadería nueva recibida de proveedores. Todo ingreso nuevo debe registrarse formalmente desde el módulo de Compras para conservar costos históricos y trazabilidad.

{# REGLAS DE INTEGRIDAD #}

Reglas de integridad del lote

  • Límite superior: Un lote nunca puede superar la cantidad inicial con la que ingresó.
  • Límite inferior: Las existencias nunca pueden quedar por debajo de cero.
  • Auditoría total: Cada modificación genera un registro histórico en MovimientoInventario y una traza de auditoría.
